### GLOSSARY

Term
Definition

**FikaMarket**
-The agricultural marketplace platform described in this document.

**Lead Farmer**
-An experienced farmer who guides buyers, verifies produce, and manages a  designated collection point.

**Collection Point**
-A  local produce pick up location  within 5–10 km of farming communities, where farmers deliver produce and buyers collect it.

**Produce Listing**
-A posted record of  the available produce that includes (crop type, quantity, price,collection point location) that buyers can browse and order from.

**Escrow**
-The payment holding account (via Flutterwave) where a buyer's payment is held until produce collection is confirmed, then released to the farmer directly.

**USSD**
-Unstructured Supplementary Service Data   a menu-based mobile protocol that works on feature phones that have no internet, used for farmer registration and produce posting.


**LocationIQ**
-A third party location API used to capture and display collection point exact location coordinates.

**Flutterwave**
-A third party payment gateway used to process  buyer payments(via escrow).

**Mobile Money**
-Telecom service digital wallet  (MTN MoMo, Airtel Money,Zamtel) used to disburse payments to farmers.

**Transaction History**
-A score derived from a farmer's platform usage history shareable with neobanks/microfinance institutions for credit applications.

**FinScope**
-A national survey ( from the Bank of Zambia / FinScope) - measuring financial inclusion in Zambia.

**GSMA**
-Global System for Mobile Communications Association, an industry body cited for mobile money/digital inclusion statistics.

**CGAP**
-Consultative Group to Assist the Poor - cited for research on group lending and financial inclusion.

**TAM**
-Technology Acceptance Model - a theoretical framework explaining technology adoption based on perceived usefulness and ease of use, used  to measure farmer digital adoption.

**Africa's Talking**
-A third party API provider used for the USSD gateway and SMS delivery/retry/delivery-status tracking.

**WFP (HDX)**
-World Food Programme (Humanitarian Data Exchange) - An external source of  live commodity market price data, updated on a scheduled  basis.

**OTP**
-One Time Passcode - a time limited numeric code sent to a users email/phone number to verify their account after registration.

**PIN**
-The 4-digit numeric code farmers use to log in via USSD.

**RBAC**
-Role-Based Access Control — restricting routes/actions based on a user's role (e.g. buyer vs. admin).

**RICE Score**
-A prioritization framework (Reach, Impact, Confidence, Effort) used alongside MoSCoW to rank FikaMarket's feature epics.

**Escrow Holding Period**
The 24–48 hour window after a buyer confirms produce collection, before payout is finally released to the farmer.

**WAF**
-Web Application Firewall - filters malicious traffic (e.g. SQL injection, bots) before it reaches the API.

**JWT**
-JSON Web Token - a signed access token FikaMarket issues after login, valid for 1 hour.

**CORS**
-Cross Origin Resource Sharing - a policy that controls which web origins may call the FikaMarket API.

**Secret Manager**
-A secure store for third party API keys, database tokens and certificates, rather than storing them in a plain configuration file.
